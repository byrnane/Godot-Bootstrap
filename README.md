# Game Template

Этот проект является универсальным шаблоном на Godot 4.x.

Цель шаблона:

- дать крепкую и понятную базу для новых игр;
- не тащить в ядро жанровую или игровую логику;
- оставаться достаточно простым для прототипов;
- выдерживать рост проекта без развала архитектуры.

Шаблон делится на два слоя.

1. Фундамент.
   Это инфраструктура, которая живет почти в любом проекте: навигация сцен, UI-оболочка, настройки, сохранения, аудио, состояние приложения и игровой сессии.
2. Демонстрационный верхний слой.
   Это небольшой набор заглушек, который показывает, как пользоваться фундаментом: главное меню, пауза, настройки, игровая сцена-заглушка, пара уровней-заглушек, базовые игровые параметры и сохранение.
