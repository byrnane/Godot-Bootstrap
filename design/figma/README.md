# Локальная выгрузка Game Template UI

Облачный оригинал: [Game Template UI](https://www.figma.com/design/le33QeQV2WWwvlW0hGpT0M/Game-Template-UI).
Локальный снимок от **21 октября 2026** находится в `2026-10-21/`:
просмотр — `index.html`, состав и SHA-256 — `manifest.json`.
Выгрузка хранится только на диске и исключена из Git; в новом клоне ее нет.
В репозитории остаются это описание и ссылка на облачный оригинал.

## Что сохранено

- Три страницы в JSON: основа, библиотека компонентов, экраны. Использован штатный
  экспорт Plugin API `JSON_REST_V1`, включая дерево, свойства и ссылки на компоненты.
- Две коллекции и 68 переменных со значениями режимов и алиасами, девять текстовых
  стилей. Отдельно — свойства компонентов и реакции прототипа, доступные через API.
- 32 SVG-превью: основа и справочник, три раздела компонентов, 27 экранов и контекстов.
- Инвентаризация: 173 компонента-мастера, 20 семейств вариантов; точные текущие
  количества узлов и файлов находятся в manifest. Растровых image fills в файле нет.

`index.html` открывается локально в браузере, без сервера и загрузки библиотек.
SVG содержат векторную графику и текст в контурах. Они подходят для просмотра;
интерактивность прототипа в них не выполняется.

## Ограничение: это не .fig

Полноценная локальная копия **`.fig` пока не сохранена**. Desktop Bridge предоставляет
данные и экспорт графики, но не команду сохранения native Figma-файла. Доступный
встроенный браузер на момент выгрузки требовал входа в Figma.
JSON и SVG не заменяют импортируемый `.fig`; восстановление библиотеки из этой
выгрузки не реализовано. Комментарии и история версий не экспортировались.

Чтобы дополнить архив: в открытом Figma-файле выберите **Main menu → File → Save local copy**
и положите полученный `Game Template UI.fig` в эту папку. Это штатная команда
[Figma](https://help.figma.com/hc/en-us/articles/8403626871063-Save-a-local-copy-of-files).
Не переименовывайте JSON или SVG в `.fig`. После сохранения обновите статус здесь
и в `docs/READINESS.md`; существующий снимок JSON/SVG оставьте с исходной датой.

## Связь с Godot

Рабочая Theme, SVG и шрифты находятся в `shared/ui/theme/`, компоненты —
в `shared/ui/components/`. Правила замены оформления и расширения библиотеки:
[UI_FRAMEWORK.md](../../docs/UI_FRAMEWORK.md).

Figma показывает варианты состояний и контекстные копии экранов для прототипа.
Godot использует собственные состояния Control и существующий стек UiShell/BaseModal.
Контекстные копии из Figma не означают дублирование экранов или логики в игре.

`design/.gdignore` исключает справочные материалы из импорта Godot.
Датированные выгрузки и локальные `.fig` также исключены из Git через `.gitignore`.
Рабочие ресурсы UI в `shared/ui/` продолжают версионироваться.
При обновлении снимка выгружайте данные из живого файла и сверяйте инвентаризацию,
а не только визуальный вид. Метод JSON-экспорта описан в
[Plugin API](https://developers.figma.com/docs/plugins/api/properties/nodes-exportasync/).
