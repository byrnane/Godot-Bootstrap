# Начало нового проекта

Текущая ветка — **2d**. [Устройство технического примера](2D_EXAMPLE.md).

Это репозиторий шаблона. Игры разрабатываются в отдельных репозиториях, созданных из выбранной ветки.

## Выберите вариант

- `main` — общая база с нейтральными заглушками.
- `3d` — технический 3D-пример, Jolt, Cyclops и Blender → GLB.
- `2d` — технический пример на Node2D с камерой и физикой.
- `2d-pixelart` — 2D-пример и пиксельный viewport 640×360.

Настройки и порядок обновления: [Варианты шаблона](VARIANTS.md).

Клонирование опубликованной ветки:

```powershell
git clone --branch 3d --single-branch git@github.com:byrnane/Godot-Bootstrap.git my-game
cd my-game
git remote remove origin
```

Затем создайте отдельный репозиторий игры и назначьте ему `origin`. Не отправляйте игровые изменения обратно в репозиторий шаблона.
Обновите README и `AGENTS.md` под игру. Правила сопровождения веток шаблона к отдельной игре не относятся; повторять в ней ветки `main`, `3d`, `2d`, `2d-pixelart` не требуется.
Пока ветки существуют только локально, вместо адреса GitHub можно указать путь `C:\GameDev\game-template`.
Клонирование берет коммиты выбранной ветки: незакоммиченные правки так не переносятся. Состояние шаблона — в [READINESS.md](READINESS.md).

## Первый запуск

```powershell
pwsh -File scripts/install_addons.ps1
```

Установщик скачивает закрепленные аддоны текущей ветки, проверяет SHA-256 и сохраняет уже установленные локальные файлы.
Godot AI нужен всем вариантам; Cyclops устанавливается только в `3d`. Новые версии движка и аддонов этой задачей не устанавливаются.

Откройте `project.godot` в Godot **4.7.2**, запустите **F5**.
Меню, HUD, пауза, настройки, RU/EN, ребинд и сохранения подключены.
Для просмотра компонентов откройте `shared/ui/catalog/ui_catalog.tscn` и нажмите **F6**.
Смена темы и добавление компонентов: [UI_FRAMEWORK.md](UI_FRAMEWORK.md).
Громкость Master по умолчанию — 15%; ранее сохраненные настройки имеют приоритет.
Пауза — **F10**, назад/закрыть модальное окно — **Escape**. Существующие пользовательские привязки сохраняются.

1. Поменяйте название проекта, иконку и метаданные Windows-пресета.
2. Замените `features/gameplay/gameplay.tscn`, `features/levels/level_a.tscn`, `features/levels/level_b.tscn` и демонстрационный HUD.
3. Расширяйте `SessionContext` и `SaveData`, добавляйте тексты в `translations/UI.csv`.

Scene IDs и gameplay/HUD-контракты одинаковы во всех ветках. При переименовании игры старый каталог `user://` автоматически не переезжает.
В PixelArt весь проект, включая UI, рисуется в 640×360. Адаптация текущих меню и модалок отложена: часть элементов пока может выходить за экран.

## Godot AI

Аддон включен в **Project Settings → Plugins**. Для работы MCP откройте редактор и дождитесь **Server connected**.
Локальная `.codex/config.toml` привязана к папке проекта и не переносится через Git; для новой игры настройте подключение отдельно.
Дока проверяет глобальную конфигурацию Codex, поэтому может показывать Not configured при рабочем проектном подключении.
Редакторские аддоны и MCP не входят в экспортированные игры.

## Windows и Web

Все варианты используют Compatibility. В **Project → Export** доступны Windows x86_64 и Web без потоков/GDExtension.

```powershell
New-Item -ItemType Directory -Force builds/windows, builds/web
godot --headless --path . --export-release Windows
godot --headless --path . --export-release Web
```

Нужны export templates той же версии, что Godot. Результаты находятся в `builds/windows` и `builds/web` и исключены из Git.
В обычном терминале Windows проверьте `godot --version`.
Для Web используйте HTTP-сервер, например `python -m http.server 8067 --bind 127.0.0.1 --directory builds/web`; `file://` не подходит.

Сейвы Web привязаны к origin; другой адрес/порт, приватный режим и очистка данных браузера влияют на их доступность.
Звук разрешается после взаимодействия, полный экран включается действием пользователя в настройках.
Кнопка выхода и автосейв при выходе в Web скрыты: закрытие вкладки не гарантирует запись, используйте слоты, таймер и чекпоинты.

`editor/export/convert_text_resources_to_binary=false` сохранено: ранее бинарная конвертация вложенных UI-сцен нарушала `%`-ссылки.
Известные предупреждения завершения Godot и ограничения приемки: [READINESS.md](READINESS.md).

## Проверка

```powershell
pwsh -File scripts/run_smoke.ps1 -Headless
```

По умолчанию запускается только `flow`: один игровой маршрут. Остальные группы и правила запуска — в [TESTING.md](TESTING.md).
Нужен PowerShell 7. Smoke использует отдельный профиль в `.local/smoke/<run-id>` и не трогает настоящие сохранения.
Успех требует PASS текущего запуска, кода 0 и отсутствия SCRIPT ERROR/ERROR.
Для проверки конфигурации конкретной ветки перед запуском задайте `$env:GAME_TEMPLATE_VARIANT = '3d'` (или `main`, `2d`, `2d-pixelart`).
Без этой переменной общий smoke также проверяет оба уровня и согласованность типов сцен.
