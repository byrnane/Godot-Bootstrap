# Технический 2D-пример

Gameplay и контейнер уровней используют Node2D; общий контроллер gameplay и HUD сохранены.
В каждом уровне есть Camera2D, пол со StaticBody2D, неподвижный ящик и падающий RigidBody2D с коллизией 32×32.
В уровне B изменены положения ящика и падающего тела. Оба уровня переключаются существующими кнопками HUD и сохраняют прежние scene IDs.

Камера без сглаживания находится в (-80, 0). Пол расположен в (0, 100), его размер — 400×24.
Пример использует обычную гравитацию Godot 2D. Контроллера персонажа нет.
Рисунок ящика — небольшой редактируемый SVG `assets/textures/demo_tiles.svg` размером 16×16, выведенный с масштабом 2×.

В `2d` используется viewport 1280×720 и линейная фильтрация.
В `2d-pixelart` весь проект рисуется в 640×360, используется nearest, целочисленное масштабирование и привязка 2D-трансформаций к пикселям.
UI между вариантами не перерабатывается; при 640×360 его адаптация остается отдельной задачей.
