## Режимы

- Лесная тропа: три коротких уровня, прыжок, огоньки, шипы, движущиеся платформы.
  Фонарь в середине уровня сохраняет контрольную точку и собранные к ней огоньки.
- Защита поляны: три волны по 6, 10 и 14 теней; преследователи и стрелки.
  Продолжение — с начала текущей волны, с полным здоровьем.
- Древние механизмы: три комнаты с ящиками и нажимными плитами. Ворота открываются,
  когда заняты все плиты. Продолжение — с начала текущей комнаты.

У платформера и арены три единицы здоровья и секунда неуязвимости после урона.
Все режимы доступны сразу. Завершение этапа сохраняет начало следующего;
завершение третьего отмечает приключение пройденным.

## Управление

| Действие | Клавиатура / мышь | Геймпад |
| --- | --- | --- |
| Движение | WASD / стрелки | Левый стик / крестовина |
| Прыжок | Space | A |
| Прицеливание | Положение мыши | Правый стик |
| Стрельба | Левая кнопка мыши | RT |
| Повтор этапа / чекпоинта | R | Y |
| Пауза | Esc / F10 | Start |

Клавиатуру и кнопки мыши можно переназначить. Для геймпада используется готовая
раскладка. Подсказки переключаются по устройству. Потеря фокуса ставит игру на паузу.

## Сохранения

`SessionContext.game_data` хранит выбранный режим, ревизию и отдельные записи
`platformer`, `shooter`, `puzzle`: этап, чекпоинт, счет, собранные огоньки и завершение.
Текущее положение, урон после чекпоинта, враги, снаряды и незаконченная раскладка
комнаты в снимок не входят. Ручной, быстрый и автоматический сейвы содержат весь
сборник; загрузка откатывает все три режима к выбранному снимку.

Переключение режима сохраняет прогресс в памяти даже при отключенном autosave.
«Начать заново» сбрасывает только выбранное приключение после подтверждения.
При отключенных автосохранениях для сохранения между запусками нужна ручная запись.

Каталог данных: `%APPDATA%/GameTemplate/ForestKeeperPixelArt`. Каталоги обычного
`2d` (`GameTemplate/ForestKeeper2D`) и прежнего технического примера (`Game Template`)
сохраняются и автоматически не импортируются.
Старые совместимые сейвы A/B при загрузке соответствуют уровням 1/2 платформера.

## Экран и ресурсы

Первый Windows-запуск — оконный, 1280×720. Сохраненные настройки имеют приоритет.
Весь проект рисуется в 640×360: `viewport + keep + integer`, nearest и привязка
2D-трансформаций к пикселям. Compatibility сохранен для Windows и Web.
ForestMenu, ForestHud и камеры пока унаследованы из `2d` и требуют адаптации
к низкому разрешению. Технический smoke не подтверждает их визуальную пригодность.
Web запускается внутри страницы. Кнопка в меню включает и выключает fullscreen;
из полноэкранного режима также можно выйти штатной командой браузера (Esc).

Девять исходных PNG находятся в `assets/forest/`, промпты встроенного ImageGen —
`art_source/forest/prompts.json`. AtlasTexture задают видимые области прозрачных
спрайтов без изменения исходных изображений. Спрайты используют nearest; изображения пока временные.

## Проверки

Штатный `pwsh -File scripts/run_smoke.ps1 -Headless -Suite flow` проверяет игровые
события, все этапы, решения комнат, сохранения, переключения и ввод. Отдельный
физический маршрут без перестановки персонажа:

```powershell
pwsh -File scripts/run_smoke.ps1 -Headless -Suite flow -Scene res://core/debug/platformer_route_smoke.tscn
pwsh -File scripts/run_smoke.ps1 -Headless -Suite flow -Scene res://core/debug/shooter_route_smoke.tscn
```

Общие `ui`, `persistence`, `transitions`, `localization`, `audio` запускаются только
для затронутых сценариев. Графическая приемка и физический геймпад проверяются
отдельно; инъекция событий не является проверкой реального контроллера.
