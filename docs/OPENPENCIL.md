# Макеты Game Template в OpenPencil

Текущий исходник: [Game Template UI.fig](<../Game Template UI.fig>).
Сохранен владельцем 23 октября 2026 года. Связь с Godot Theme и компонентами
описана в [UI_FRAMEWORK.md](UI_FRAMEWORK.md). Проверка макета не заменяет
приемку UI в Godot.

## Порядок работы

Используй официальный навык `open-pencil`, MCP или CLI. Начинай со списка
документов; явно задавай актуальные `document_id` и `page_id`. Идентификаторы
после повторного открытия меняются: ищи страницы и компоненты по именам.
Редактор загружает страницы постепенно; обратись к каждой перед проверкой
всего документа. Для CLI задавай `OPENPENCIL_MCP_ROOT` равным каталогу проекта.

Сохраняй компоненты, переменные, арт, тексты и индивидуальные правки экземпляров.
Общие свойства меняй через исходный компонент или переменную. После правки
проверяй PNG нужного экрана, шрифты, изображения, связи и повторное открытие.
Пробное сохранение делай в отдельную временную копию через `documents save
--path`; исходник ради проверки не перезаписывай. Не редактируй один файл
одновременно в приложении и headless-режиме CLI.

`.fig` — основной формат чтения и записи OpenPencil 0.16.0. `.pen` доступен
только для чтения; переименовывать файлы и создавать второй текущий мастер
не нужно. Старые облачные ссылки и указания — история, работа идет локально.
Дизайн при техническом переходе редактора не меняется.
