# Локальные проверки

При правках запускайте только проверки измененного поведения. Полный прогон
нужен перед финальным коммитом по задаче, по просьбе владельца или при крайней
необходимости с конкретным объяснением причины. Актуальные результаты повторно
не прогоняйте. GitHub Actions и другой CI без поручения владельца не добавляйте.

```powershell
pwsh -File scripts/run_smoke.ps1 -Headless -Suite flow
```

| Группа | Когда нужна |
| --- | --- |
| `flow` (по умолчанию) | Меню, игра, HUD, уровни, пауза/настройки, сохранение и продолжение; конфигурация варианта при заданной `GAME_TEMPLATE_VARIANT` |
| `ui` | Компоненты, координатные клики через UiShell, колонки биндингов и отступ скролла, отмена черновика настроек, создание первого слота |
| `persistence` | Данные и миграции, восстановление backup, ввод, настройки, ошибки записи и Retry при выходе |
| `transitions` | Очередь переходов, неизвестная сцена, переопределение стартовой сцены, пауза во время загрузки и модалки |
| `audio` | Аудиошины, UI-звук и музыка |
| `localization` | Покрытие ключей и переключение языка |
| `all` | Все оставленные группы по одному разу |

Если изменение затрагивает несколько областей, запустите соответствующие группы.
Для документации Godot не нужен. Проверки точной структуры фокуса и оформления,
а также повторный проход того же игрового маршрута удалены.

Визуальная проверка UI: F6 для `shared/ui/catalog/ui_catalog.tscn`, затем обычный
запуск `main/main.tscn` и затронутые экраны. Проверьте RU/EN, мышь, клавиатурный
фокус и целевой размер окна. Headless `ui` не подтверждает внешний вид;
эмулированные Joypad-события не заменяют физический геймпад.
Автоматизированные графические проверки запускайте с `--audio-driver Dummy`,
чтобы не включать звук; аудиопроверку проводите отдельно.

Полный локальный прогон:

```powershell
pwsh -File scripts/run_smoke.ps1 -Headless -Suite all
```

Используйте PowerShell 7 и штатный wrapper: он изолирует пользовательские данные
в `.local/smoke/<run-id>`. Прямой запуск тестовой сцены запрещен.
Успех: `PASS` текущего запуска, код выхода 0 и отсутствие `SCRIPT ERROR`/`ERROR`.
Журналы `stdout.log`, `stderr.log` и файл `phase0_smoke_result.txt` находятся
в каталоге запуска. Проверяйте первое сообщение об ошибке; после исправления
повторяйте только затронутую группу.

Устанавливайте аддоны и импортируйте ресурсы только при необходимости подготовки
окружения. Экспорт Windows/Web и ручные проверки выполняйте только для изменений,
которые требуют проверки экспорта, платформы или визуального поведения.
Обновление общей логики не требует повторения всех групп в каждом варианте:
отдельно проверяйте варианты, чье представление или настройки затронуты.
