# Выбор renderer для 3D-примера

Ветка `3d` использует **Mobile с Direct3D 12 на Windows** и
**Compatibility/WebGL 2 в Web**. Настройка Windows:
`rendering/rendering_device/driver.windows="d3d12"`.

В Compatibility/OpenGL наблюдалось тяжелое торможение обычного редакторского
запуска и Windows EXE. Переход на Mobile/Direct3D 12 устранил наблюдавшийся сбой.
Одновременно изменились renderer и графический API, поэтому точная причина
не установлена: данные не позволяют приписать ее OpenGL, Godot, драйверу или ОС.

Уже открытый редактор сохраняет прежний renderer до перезапуска. Новый EXE
получает конфигурацию при сборке. Web продолжает использовать Compatibility;
Windows и Web приняты 28 октября 2026 в объеме, указанном
в [3D_WORKFLOW.md](3D_WORKFLOW.md#ручная-приемка--28-октября-2026).

Внутренний счетчик FPS не доказывает плавность изображения на экране.
При диагностике рывков нужны данные о времени кадров и реальном отображении,
а не только средний FPS. Лимит 60 FPS не применялся; VSync остается
пользовательской настройкой.
