# Варианты шаблона

Репозиторий содержит только шаблон. Каждая игра развивается в отдельном репозитории после клонирования выбранной ветки.

| Ветка | Состав | Viewport и фильтрация |
| --- | --- | --- |
| `main` | Общие сервисы, UI и нейтральные Control-заглушки | 1280×720, canvas_items, linear |
| `3d` | Node3D, камера, свет, модели, коллизии, Jolt, Cyclops, Blender → GLB | 1280×720, canvas_items, linear |
| `2d` | Node2D, Camera2D, статические и падающие тела, два уровня | 1280×720, canvas_items, linear |
| `2d-pixelart` | Технический 2D-пример на пиксельной сетке | 640×360, viewport, integer, nearest |

Во всех ветках: Godot 4.7.2, Compatibility, Windows/Web, сохранение пропорций, стартовое окно 1280×720.
Godot AI общий. Cyclops и его export plugin входят только в `3d`.
Идентификаторы сцен и формат сохранений одинаковы. Путь игровой сцены — `features/gameplay/gameplay.tscn`, уровней — `features/levels/level_a.tscn` и `level_b.tscn`.

## PixelArt и UI

В PixelArt низкое разрешение применяется ко всему проекту, включая меню и HUD.
Текущий UI сохранен без изменений и пока может выходить за экран при 640×360. Его адаптация — отдельная задача.
При целочисленном масштабировании свободное место окна заполняется полями; растягивать изображение дробно для заполнения окна не нужно.

## Развитие шаблона

Все три варианта ответвлены непосредственно от `main`.
Общие изменения делайте в `main`; особенности мира, настройки и дополнительные аддоны — в своей ветке.
После общего изменения влейте `main` в каждый вариант:

```powershell
git switch 3d
git merge main
git switch 2d
git merge main
git switch 2d-pixelart
git merge main
```

После каждого merge установите аддоны текущей ветки, импортируйте ресурсы и запустите smoke. Конфликты настроек решайте с сохранением параметров варианта из таблицы.
Не вливайте целиком вариант обратно в `main`: вместе с общим исправлением туда попадут его мир и настройки.
Если общий дефект найден в варианте, оформите исправление общих файлов отдельным коммитом и перенесите его в `main`, затем обновите варианты.

```powershell
pwsh -File scripts/install_addons.ps1
godot --headless --editor --path . --import
$env:GAME_TEMPLATE_VARIANT = git branch --show-current
pwsh -File scripts/run_smoke.ps1 -Headless
Remove-Item Env:GAME_TEMPLATE_VARIANT
```

CI выполняет установку, импорт и тот же smoke для четырех веток. Для новой игры на произвольно названной ветке переменная не нужна.
Копии игр обновления шаблона автоматически не получают.

## Локальные файлы

`.local`, `.godot`, `builds`, установленные сторонние аддоны и локальная конфигурация MCP не входят в Git.
При переключении веток установленные игнорируемые аддоны остаются на диске: используйте отдельные клоны для вариантов либо перенесите ненужный аддон за пределы проекта.
Установщик сохраняет существующие локальные файлы и не удаляет чужие данные.
Для новой игры настройте MCP на ее папку отдельно.
