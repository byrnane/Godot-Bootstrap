# Макеты Game Template в Figma

Рабочий исходник — [Game Template](https://www.figma.com/design/le33QeQV2WWwvlW0hGpT0M/Game-Template-UI). Локальный `Game Template UI.fig` — резервный
снимок, а не второй рабочий мастер. Макеты редактируются в Figma Desktop через
локальный figma-console-mcp и Desktop Bridge. Явно указывай fileKey и проверяй
контекст ответа; инструменты без fileKey используй с закрепленным файлом.

Сохраняй компоненты, переменные, тексты, изображения и правки экземпляров.
Общие свойства меняй в мастере. После содержательных правок проверяй нужный экран
и текущее состояние документа через MCP. Ручное сохранение, переоткрытие файла
и подтверждение облачного сохранения оставляй владельцу по глобальным правилам.
Проверка макета не заменяет приемку приложения.

## Локальная резервная копия

На момент возврата 23 октября 2026 года файл побайтно совпадает со снимком
предыдущего перехода. Страницы: «00 · Основа», «01 · Компоненты», «02 · Экраны»; 173 компонента и 900 экземпляров.
Эти числа описывают резервный файл и сами по себе не доказывают качество дизайна.
Дизайн и код в рамках возврата не изменяются.
