# Макеты Game Template в Figma

Рабочий исходник — [Game Template](https://www.figma.com/design/le33QeQV2WWwvlW0hGpT0M/Game-Template-UI).
Макеты редактируются в облачном документе через Figma Desktop. Локальный
`Game Template UI.fig` — резервный снимок этого документа, включенный в репозиторий.

При редактировании сохраняйте компоненты, переменные, тексты, изображения
и индивидуальные правки экземпляров. Общие свойства меняйте в основном компоненте.
После содержательных правок проверяйте затронутые экраны. Проверка макета
не заменяет приемку приложения.

## Резервная копия в репозитории

Резервная копия содержит страницы «00 · Основа», «01 · Компоненты» и «02 · Экраны».
Она хранит состояние макета на момент экспорта и не обновляется автоматически
при изменении облачного документа.
