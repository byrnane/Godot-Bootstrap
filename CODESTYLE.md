# Кодстайл

Основные правила:

- используем `=` вместо `:=`;
- ставим `;` в конце выражений;
- используем строгую типизацию везде, где это полезно;
- избегаем хардкода и магических значений;
- все параметры, которые логично менять из редактора, выносятся в `@export`;
- порядок содержимого файла держим близко к Godot guideline.

Порядок в файле:

1. `class_name` и `extends`
2. `signal`
3. `enum`
4. `const`
5. `@export` поля
6. публичные поля
7. приватные поля
8. `@onready` поля
9. lifecycle methods
10. публичный API
11. приватные методы
12. signal handlers
