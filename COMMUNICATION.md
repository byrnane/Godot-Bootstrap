# Коммуникация Модулей

Шаблон не использует глобальный `EventBus` на все случаи.

Разрешенные способы коммуникации:

1. Typed API между инфраструктурными сервисами.
2. Локальные сигналы конкретных модулей.
3. Стабильные command and gateway-точки для верхнеуровневых действий.
4. `AppContext` и `SessionContext` как единый источник состояния.

Запрещено:

- прямой `change_scene` вне `SceneRouter`;
- вызовы файловой системы из feature-сцен;
- хранение состояния одновременно в сервисе и в контексте.
