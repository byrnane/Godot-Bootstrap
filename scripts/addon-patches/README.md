# Патч завершения Cyclops 1.5.1

`cyclops-1.5.1-cleanup.patch` применяется штатным
`pwsh -File scripts/install_addons.ps1` в ветке `3d`.
Исходный архив, версия и SHA-256 остаются закреплены в `addons.lock.json`.
Полные исходники аддона в Git не добавляются.

Патч исправляет владение узлами редакторского плагина:

- освобождает четыре окна импорта/экспорта и UV-панель, даже если они не открывались;
- освобождает viewport manager и неактивные панели, снимает toolbar;
- закрепляет созданные без родителя snapping systems за плагином;
- освобождает заменяемые редакторы свойств и сохраняет повторное назначение текущего.

Установщик распознает уже примененный патч. Если локальные файлы не совпадают
ни с исходным, ни с исправленным состоянием, он останавливается без перезаписи.
Проверка нового архива: установка в изолированном каталоге тем же установщиком;
проверка завершения: обычный редакторский импорт с `--verbose`, затем `flow`.

Контекст unified diff содержит исходные табуляции и пробелы Cyclops. Атрибут
`whitespace` для этого файла учитывает формат патча; добавленные строки и
применимость патча проверяются отдельно.
